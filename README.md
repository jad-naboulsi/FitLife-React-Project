# FitLife React Project

FitLife is a fitness and nutrition website made using ReactJS and CSS.

The website includes:
- Workout programs
- Nutrition ideas
- BMI calculator
- Calories calculator
- Responsive design for mobile and desktop

Technologies used:
- ReactJS
- CSS3
- Vite
- React Router

How to run the project:

1. Open terminal
2. Run:
npm install

3. Then run:
npm run dev
