# FitLife - Fitness and Nutrition Web Application

FitLife is a ReactJS fitness web application created for CSCI390 Web Programming Project Phase 2. The website helps users explore workout programs, nutrition ideas, and basic fitness guidance. It also includes BMI and calories calculators, plus a workout filter as interactive features.

## Features

- Home page with fitness introduction
- Workouts page with bodybuilding and calisthenics sections
- Nutrition page with simple meal ideas
- About page explaining the project idea
- Contact page with a simple message form
- BMI calculator using React state
- Calories calculator for maintenance, bulking, and cutting estimates
- Workout filter by type and difficulty level
- Responsive design for desktop, tablet, and mobile

## Technologies Used

- ReactJS
- React Router
- CSS3
- Vite
- Git and GitHub
- Vercel / Netlify / GitHub Pages for deployment

## Setup Instructions

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Install dependencies:

```bash
npm install
```

4. Run the project locally:

```bash
npm run dev
```

5. Build the project for deployment:

```bash
npm run build
```
